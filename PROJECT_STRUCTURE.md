# Disgame - Project Structure

## Overview
This Godot 4.5 project follows standard organizational best practices for 3D game development.

## Directory Organization

### `/scenes/` - Game Scenes
```
scenes/
├── levels/                    # Playable game levels
│   └── main_level.tscn       # Main gameplay scene with first-person controller
├── ui/
│   ├── menus/                # Menu scenes
│   │   ├── lobby.tscn        # Main menu/lobby
│   │   ├── pause_menu.tscn   # In-game pause menu
│   │   └── options_menu.tscn # Options/settings menu
│   └── hud/                  # HUD and UI elements
│       └── fps_counter.tscn  # FPS display widget
```

### `/scripts/` - Game Code
```
scripts/
├── player/                   # Player controller scripts
│   └── first_person_controller.gd  # Main player logic
├── ui/
│   ├── menus/               # Menu logic
│   │   ├── lobby.gd         # Main menu controller
│   │   ├── pause_menu.gd    # Pause menu controller
│   │   └── options_menu.gd  # Options menu controller
│   └── hud/                 # HUD logic
│       └── camera_mover.gd  # Camera preview in menus
└── managers/                # Game system managers
    └── (manager scripts)
```

### `/assets/` - Game Assets
```
assets/
├── models/                  # 3D models
│   └── characters/
│       ├── player/         # Player character models
│       └── animations/     # Animation data
├── textures/               # Texture files
│   ├── ui/                # UI textures
│   ├── environment/       # World textures
│   └── prototype/         # Prototype/placeholder textures
├── audio/                  # Audio files
│   ├── sfx/               # Sound effects
│   └── music/             # Background music
└── environment/           # Environmental assets
    ├── sky/               # Skybox textures
    └── materials/         # Reusable materials
```

## Naming Conventions

- **Files**: `snake_case` (e.g., `first_person_controller.gd`)
- **GDScript Classes**: `PascalCase` (e.g., `FirstPersonController`)
- **Folders**: `lowercase` with underscores (e.g., `first_person_controller/`)
- **Scene Nodes**: `PascalCase` (e.g., `Player`, `PauseMenu`)

## Key Files

| File | Purpose |
|------|---------|
| `project.godot` | Project configuration and input mappings |
| `scenes/ui/menus/lobby.tscn` | Entry point scene (main menu) |
| `scenes/levels/main_level.tscn` | Main gameplay level |
| `scripts/player/first_person_controller.gd` | Core player mechanics |

## Input Actions
All input actions defined in `project.godot`:
- `ui_cancel` - Escape key (pause/menu navigation)
- `move_forward/back/left/right` - WASD movement
- `sprint` - Shift (speed boost)
- `jump` - Space
- `crouch` - C
- `switch_view` - V (first/third-person toggle)
- `lock_on` - Q
- Plus action/aim animations

## Architecture

### Player System
- `FirstPersonController` handles movement, animation, and dual-camera setup
- Supports first-person and third-person perspectives
- Integrates pause menu system at runtime

### UI System
- `Lobby` - Main menu navigation
- `PauseMenu` - In-game pause with resume/options
- `OptionsMenu` - Settings interface
- `CameraMover` - Camera preview in menu scenes

### Asset Pipeline
- All import metadata (`.import` files) auto-generated by Godot
- Models reference animation libraries from `.glb` files
- Textures organized by use case for easy iteration

## Best Practices Applied

✅ Clear separation of concerns (scenes, scripts, assets)
✅ Logical grouping by functionality (player, ui, managers)
✅ Consistent naming conventions
✅ Single-responsibility scripts
✅ Organized asset library
✅ Modular scene structure for reusability
